# Typical wrong turns

| Situation | Required reaction |
|---|---|
| Reviewer is senior and sounds sure | Still verify. Seniority is not evidence. |
| Comment says "nit" | Still classify. Nits get fixed or explained, cheaply. |
| Twelve threads, all small | Still one reply each. Batching hides skipped ones. |
| Fix is obvious, just do it | Ledger first, then fix. |
| Reviewer asks for something the agreements forbid | explain, citing the agreement. Leave the code as it is. |
| User approved the replies but not the push | Post explain, clarify and out-of-scope replies. Hold the fix replies until the push. |
| Thread is outdated after your fix | Reply anyway with the commit; resolve only after the yes. |
| Reviewer disagrees with an explain reply | Leave the thread open. They close it, not you. |
