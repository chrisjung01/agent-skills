# Scenarios

Paper exercises per skill, built from real sessions. A scenario is evidence for a change only when it tells the versions apart: run it against the skill before the change and after, and write both outcomes under Results as "met expected" or "missed expected". A case the old text already handles proves nothing about the new one; rewrite it or drop it. A setup that starts after the new behaviour has happened ("the challenge ran") passes on the old text too: start it where the user types the command. A test seam that names several catches gets one case per catch.
